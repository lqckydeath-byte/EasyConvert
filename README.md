EasyConvert
===========
Легкий набор конвертеров (калькулятор, площадь, куб, температура, вес, память, время и даже измеритель удачи) в Django-приложении.

Быстрый старт
------------
1. Убедитесь, что установлен Python 3.8+.
2. Создайте виртуальное окружение и активируйте его.

PowerShell (Windows):

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

3. Установите Django напрямую:

```powershell
pip install django
```

4. Запустите сервер:

```powershell
python manage.py migrate
python manage.py runserver
```

Где что находится
-----------------
- Шаблоны: `converters/templates/`
- Статика: `converters/static/converters/styles.css`
- Основной файл запуска: `manage.py`
- Приложение: `converters/`
